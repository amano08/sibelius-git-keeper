# サンプル譜面について

このフォルダは、セットアップ後の「試し運転」に使うサンプル用の曲フォルダです。

## sample_song.sib について

- ここには `sample_song.sib`（自作の数小節だけの短い譜面）が置かれています
- サンプル譜面は、配布者が Sibelius 本体で実際に作成したものです。**ダミーのファイルを .sib として置くことはしません**（開けないファイルをサンプルとして配る意味がないためです）

## 試し運転の手順

1. `sample_song.sib` を Sibelius で開きます
2. 音符を1つ書き換えるなど、小さな編集をします
3. Cmd+S（プラグインの「gitと併せて保存」）で保存します
4. GitHub の repo ページで commit が増えていることを確認します

確認できたら導入は完了です。このフォルダは削除しても構いませんし、残しても実害はありません。

## このフォルダの .gitignore について

このフォルダの .gitignore は、曲フォルダ用既定値の実物見本です。

```
*
!*.sib
!.gitignore
```

この内容により、このフォルダでは .sib と .gitignore 以外は repo に上がりません。
